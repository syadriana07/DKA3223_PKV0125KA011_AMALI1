# DKA3223_PKV0125KA011_AMALI1
Pembangunan Repositori dan Pipeline AI bagi Model Computer Vision
1. Pengenalan Projek
Repositori ini mengandungi pelaksanaan model Computer Vision menggunakan Convolutional Neural Network (CNN) dan YOLO (You Only Look Once). Projek ini bertujuan untuk memberi kefahaman mendalam mengenai pemprosesan imej, pengelasan, dan pengesanan objek secara beretika dalam aplikasi Smart City serta Smart Manufacturing.

2. Kandungan Repositori
01_CNN_Simulation.ipynb: Simulasi pembelajaran mendalam berasaskan arkitektur CNN untuk klasifikasi imej.
02_YOLO_Object_Detection.ipynb: Pelaksanaan model YOLO bagi pengesanan objek secara real-time.
3. Sumber Rujukan dan Harta Intelektual (Intellectual Property)
Projek ini dibina berasaskan sumber terbuka berikut:

Kod Rujukan: Google Colab Tutorials, Dokumentasi Rasmi Ultralytics (YOLO), dan TensorFlow/Keras Framework.
Dataset: Dataset terbuka daripada Kaggle / Roboflow.
Penafian Hak Cipta: Semua hak cipta bagi dataset dan pustaka asal adalah milik pereka/penulis asal. Penggunaan dalam repositori ini adalah bagi tujuan akademik semata-mata.
4. Etika Profesional AI, Limitasi Model & Tanggungjawab Pengguna
Privasi Data: Pastikan tiada maklumat peribadi (PII) atau data sensitif dimuat naik tanpa kebenaran.
Bias & Limitasi Model: Model ini dilatih menggunakan dataset terhad dan mungkin menunjukkan penurunan ketepatan (accuracy drop) pada persekitaran pencahayaan rendah atau sudut paparan yang berbeza.
Penggunaan Beretika: Model ini TIDAK BOLEH digunakan untuk pengawasan tanpa kebenaran (unauthorized surveillance) atau sebarang tindakan yang melanggar hak privasi individu.
